The 3 pieces

Three new MCP pieces. Each one solves a fear.

Each piece has its own animated flow, an everyday example and the real screen from the demo.

Manual included

Piece 1

The manual that comes along

So you don't repeat the rules in every conversation.

Besides the buttons the AI can press, the connector delivers the manual on how to use them, written by the tool's own company. The AI opens the manual only when needed, so it takes up almost no room in the conversation. In the kit, the demo checks that the manual arrived complete.

Like in everyday life: an appliance that comes with the manual in the box, and the maker swaps the manual for you when it gets better.

  • Public beta
  • Claude Code v2.1.331 or newer
  • ~30 tokens until used

Official name: Skills over MCP (the server lists and delivers the manuals). In real tools: Shopify, HubSpot, Atlassian.

Background

Piece 2

Background work

So a long job doesn't freeze the conversation.

Instead of leaving you waiting, the tool replies right away "got it, I'm working" and carries on by itself. The AI checks from time to time and tells you when it's done. In the kit, progress shows up 50 at a time until "done". One product kept its old price: with the minimum margin, there was no real discount to give.

Like in everyday life: dropping your clothes at the cleaners and getting a ticket. You leave and come back to ask if they're ready.

  • Available
  • Pro, Max and Ultra
  • Team and Enterprise: rolling out gradually

Official name: Tasks (the server returns a ticket and the client asks how it's going). In a real tool: ZoomInfo.

Asks first

Piece 3

The question before acting

So nothing irreversible happens without your yes.

In the middle of the job, the tool stops and asks you. It can be a question right in the chat (yes or no, type the name) or a link to the company's website, for a password or payment: that way sensitive data doesn't go through the chat. In the kit, to delete, typing just "Caneca" is not enough: it has to be "Caneca Azul P".

Like in everyday life: the bank that asks you to confirm the amount before a transfer.

  • Available
  • Pro, Max and Ultra
  • 2 safety locks in the kit

Official name: Elicitation (question in the chat or link to the website). In real tools: Supabase shows the cost before creating a paid project, Railway asks before removing a service and GitHub requires you to type the repository name before deleting it.

Questions

Questions before you start

Do I need to code?

To see it working, no: you paste the request and your AI does the rest. To build your own connector, yes, and the Python kit is the starting point.

Does it cost anything?

The kit is free and open (MIT license). The new features in Claude are turned on in the Pro, Max and Ultra plans, which are paid.

Does it work with other AIs?

MCP is open: ChatGPT, Claude, Cursor, Gemini, Microsoft Copilot and Visual Studio Code support it. Each AI app needs to accept the new pieces; the kit was tested in Claude Code. The demo runs by itself in the terminal, with any agent.

What is a connector?

It's the piece that links the AI to a program (the store, the database, the company's tool). In MCP it's called a server. With the standard, one connector works for any AI that speaks MCP.

Can I send a file to the tool?

Not yet. File uploads were announced as "coming soon", with no date.
